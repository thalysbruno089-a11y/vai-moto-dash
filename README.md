# Vai Moto

Sistema interno de gestão de entregas, motoboys, clientes e financeiro.

## Tecnologias

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Uso restrito e privado. Todos os direitos reservados.
